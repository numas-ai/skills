# numas 全景图插件（numas.panorama）

打开 `*.pano` / `*.panorama` 数据文件，在 IDE 里渲染成可缩放、可拖拽编辑的架构图。
改动自动写回文件，不需要手动保存。

## 一、能做什么

- 双击文件即在 IDE 里打开成图（不是文本编辑器）
- 拖节点、改大小、改标题、加删节点
- 拖出连线、改连线端点、加标签
- 标记箭头（条件分支）与虚线（可选/非主链路）
- 缩放、适应窗口、居中
- 改动 600ms 后自动写回文件

## 二、怎么打开

| 方式 | 操作 |
| --- | --- |
| 双击文件 | 在资源管理器里双击 `*.pano` / `*.panorama`，默认就用全景图打开 |
| 命令面板 | `Numas: 打开全景图` |
| 右键菜单 | 在 `.pano` 文件上右键 →「打开全景图」 |

前提：文件后缀是 `.pano` 或 `.panorama`，内容是合法 YAML（JSON 也能读）。

## 三、界面与操作

| 操作 | 效果 |
| --- | --- |
| 单击节点 | 选中，出现 8 个缩放手柄 |
| 拖动节点 | 移动，连线自动重算正交路径 |
| 拖手柄 | 改宽高 |
| 双击节点 | 就地改标题 / 副标题 |
| 悬停节点四边中点 | 出现小圆点，拖出即新建连线 |
| 拖连线端点 | 改接入的节点 / 边 / 位置（保持垂直于边） |
| 双击连线 | 就地改标签 |
| 单击连线 | 出现工具条：箭头 / 虚线 / 自动 / 删除 |
| 选中节点后 Delete | 删除节点及其连线 |
| 滚轮 / 底部按钮 | 缩放、适应窗口、居中 |
| 顶部图例 | 由 `bands` 自动生成，不用手画 |

## 四、文件格式

```yaml
title: ''
subtitle: ''
canvas:
  w: 1600
  h: 900
nodeHeight: 72
bands:
  - id: app
    label: webapp
    color: '#58a6ff'
nodes:
  - id: start
    band: app
    title: 开始
    sub: 副标题
    x: 120
    'y': 160
    w: 200
    h: 72
edges:
  - from: start
    to: end
    url: 连线上的文字
```

| 层级 | 字段 | 必填 | 说明 |
| --- | --- | --- | --- |
| 根 | `canvas.w` / `canvas.h` | 是 | 画布逻辑尺寸，影响「适应/居中」 |
| 根 | `nodeHeight` | 否 | 新节点的默认高度，缺省 72 |
| root | `title` / `subtitle` | 否 | 目前只存不显示，留空即可 |
| band | `id` / `label` / `color` | 是 | 层：图例文字与颜色（`#rrggbb`），节点按 `band` 取色 |
| node | `id` / `band` / `title` | 是 | `id` 唯一，被连线引用 |
| node | `sub` | 否 | 副标题 |
| node | `x` / `y` / `w` / `h` | 是 | 左上角坐标与宽高（px） |
| edge | `from` / `to` | 是 | 两端节点 id |
| edge | `url` | 否 | 连线上的标注文字（字段名叫 url，实际是任意文本） |
| edge | `sSide` / `tSide` | 否 | 接入边：`top` `right` `bottom` `left` |
| edge | `sRatio` / `tRatio` | 否 | 接入点在边上的位置，0–1 |
| edge | `arrow` / `dashed` | 否 | `true` 画箭头 / 虚线 |
| edge | `sourcePort` / `targetPort` | 否 | 编辑器自动维护，手写一般不需要 |

不写 `sSide`/`tSide` 时，编辑器按几何自动选最近的边；想固定走线再手工写。

## 五、从零画一张

1. 新建 `xxx.pano`，先写 `canvas` 和 `bands`（决定配色与图例）
2. 按层摆节点：同一层的 `y` 对齐，横向留 40px 以上间距
3. 加连线：只写 `from` / `to` / `url`，走向交给编辑器
4. 只有**条件分支**才加 `arrow: true`；可选路径用 `dashed: true`
5. 在 IDE 里打开，按需拖拽微调；改动会自动保存

坐标不用一次到位——先摆大概位置，剩下的在界面里拖。

## 六、保存与同步

- 任何改动后 **600ms 自动写回**文件，不用点保存
- 文件被外部修改时，编辑器会把新内容推回视图重新渲染
- 文件格式统一写成 YAML（原有 JSON 文件也能打开，保存后变 YAML）

## 七、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 打开是文本不是图 | 后缀不是 `.pano` / `.panorama`；或扩展未安装，见安装说明 |
| 打开一片空白 | YAML 解析失败：检查缩进、是否混入 tab、是否用了中文冒号 |
| 节点没颜色 / 图例少一项 | `node.band` 引用了不存在的 `band.id` |
| 连线指向空气 | `edge.from` / `edge.to` 拼错，或节点 id 改过没同步 |
| 线斜着走 | 手工写了 `sSide` 后节点位置又变了；删掉该字段让编辑器重算 |
| `y` 字段被写成 `'y'` | 正常：YAML 解析器会把 `y` 加引号，两种写法都能读 |

## 八、现成示例

`examples/panorama/` 下有两个可直接打开的文件，建议拷一份改：

| 文件 | 内容 |
| --- | --- |
| `hello.pano` | 最小示例：2 节点 / 1 连线 |
| `webapp.pano` | 分层 Web 应用：接入层 → 应用层 → 基础设施层，含一条条件分支 |

## 九、生成后自检

```bash
node skills/panorama/scripts/check.mjs <文件.pano>
```

校验结构：字段齐全、id 唯一、`band` 引用存在、连线两端存在、`sSide`/`ratio` 合法、节点是否越出画布、节点是否重叠。
输出 `PASS` 表示结构上能被插件正常打开；`FAIL` 会指出具体节点/边。
